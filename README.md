# Kotlin Android Login and Registration App

## 📱 About the Project

This project is an Android application developed using **Kotlin and XML in Android Studio**. It provides a simple user authentication interface with registration, login, and home page screens.

The application allows users to create an account, log in using their email and password, access the home page, and log out.

## ✨ Features

### 1. User Authentication Screen
- Simple welcome screen
- Login button to open the login screen
- Register button to open the registration screen

### 2. Registration Screen
- Full name input field
- Email input field
- Password input field
- Confirm password input field
- Register button
- Navigation to the login screen for existing users

### 3. Login Screen
- Email input field
- Password input field
- Login button
- Create New Account button for new users

### 4. Home Page
- Welcome message
- Display email address
- Logout button to return to the authentication flow

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open Android Studio.
3. Select **Open** and choose the downloaded project folder.
4. Wait for Gradle synchronization to finish.
5. Start an Android emulator or connect an Android device.
6. Click **Run** to launch the application.
